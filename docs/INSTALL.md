# インストール

1. `SwitchBotScreenSaver-macos.zip`を展開します。
2. `SwitchBotScreenSaver.saver`をダブルクリックし、OSの案内に従って「このユーザのみ」にインストールします。
3. システム設定のスクリーンセーバーで「SwitchBot Screen Saver」を選択します。
4. 「オプション」を開きます。最初はサンプル表示です。
5. 実測値を表示するにはサンプル表示をオフにし、Open TokenとSecretを入力して「接続して機器を取得」を押します。機器を選択して「保存して表示に反映」を押してください。保存後は表示側も設定を読み直し、実測値の取得を開始します。

時計はOS側の表示をご利用ください。温湿度は5分ごとに取得します。通信に失敗した場合は最後の値と最終取得時刻・更新停止を表示し、未取得の値は「—」になります。

背景は黒、温湿度は通常のカード表示です。Liquid Glassの選択肢は削除しました。

認証情報はMacのKeychainに保存します。チャットやファイルに貼り付ける必要はありません。Keychainへのアクセス許可をOSが求めた場合は、利用するスクリーンセーバーホストであることを確認してください。ホストから読み取れない場合は、プレビューアプリではなくシステム設定の「オプション」で設定し直してください。

## 試用版の制限

現在のZIPはローカル検証用のad-hoc署名です。Developer ID署名・公証済みの一般配布版ではありません。OSがブロックした場合はセキュリティ設定を無効化せず、開発用MacでXcodeから検証してください。一般配布向けの署名・公証と、OSホストでのKeychainアクセスは引き続き検証が必要です。

## 更新・削除

更新時はスクリーンセーバーとシステム設定を終了して、新しい`.saver`を開き、同名のバンドルを置き換えます。システム設定を開き直して「オプション」を確認してください。ホストが旧バンドルを保持する場合はログアウトして再度ログインしてください。

認証情報を削除する場合は先に「オプション」→「認証情報を削除」を使ってください。その後、システム設定で削除するか、Finderで`~/Library/Screen Savers/`内の`SwitchBotScreenSaver.saver`を削除します。バンドルを削除するだけではKeychainの認証情報は消えません。
