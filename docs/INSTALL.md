# インストール

1. `SwitchBotScreenSaver-macos.zip`を展開します。
2. `SwitchBotScreenSaver.saver`をダブルクリックし、OSの案内に従って「このユーザのみ」にインストールします。
3. システム設定のスクリーンセーバーで「SwitchBot Screen Saver」を選択します。Appleが検証できないという警告が出た場合は「完了」で閉じます。
4. **システム設定 → プライバシーとセキュリティ**の下部に、この`.saver`の「このまま開く」が表示されていれば押し、OSの確認・認証に従います。このリポジトリから取得した配布物を対象にしてください。
5. システム設定を⌘Qで終了し、開き直してスクリーンセーバーを選択します。「オプション」の「表示」タブで時計・温度・湿度・日付を個別に選びます。最初はすべてオン・24時間表示です。
6. 初回に実測値を表示するには「SwitchBot」タブでサンプル表示をオフにし、Open TokenとSecretを入力して「接続して機器を取得」を押します。機器を選択して「保存して表示に反映」を押してください。更新時は保存済みの設定と認証情報を引き継ぎます。

この許可手順はmacOS 27でユーザーが実施し、Gatekeeperによる読み込み拒否を解消できたことを確認済みです。OSのバージョンにより画面の文言・位置は異なる場合があります。

時計は12／24時間を選べます。日付の並び・区切りとカレンダーはMacの設定に合わせ、曜日だけ英語の略称（Mon等）です。日付のスラッシュ前後にはスペースを入れます。時計・日付はMacの時刻・タイムゾーンに従います。温度・湿度を両方オフにすれば認証情報は不要です。4項目ともオフなら黒画面になります。

温湿度は5分ごとに取得します。通信に失敗した場合は最後の値と更新停止・エラーを表示し、未取得の値は「—」になります。最終取得時刻は画面に表示しません。

背景は黒、選んだ時計・温湿度を四角い枠内に横並びで表示し、日付を下部に表示します。OSのDIN系フォントを使い、利用できない場合はシステムフォントに切り替えます。フォントファイルは同梱しません。Liquid Glassの選択肢は削除しました。

認証情報はMacのKeychainに保存します。チャットやファイルに貼り付ける必要はありません。Keychainへのアクセス許可をOSが求めた場合は、利用するスクリーンセーバーホストであることを確認してください。ホストから読み取れない場合は、プレビューアプリではなくシステム設定の「オプション」で設定し直してください。

## 配布方式と一覧に出ない場合

無料配布とし、配布者のApple Developer Programへの有料登録、Developer ID署名・公証は行いません。現在のビルドはad-hoc署名です。Appleの公証による検証済み表示にはならず、利用者が上記のOSの許可操作を行います。セキュリティ機能全体の無効化は不要です。

インストールが完了しても一覧に出ない場合は、Finderの⌘⇧Gで`~/Library/Screen Savers/`を開き、`SwitchBotScreenSaver.saver`があることを確認します。「すべてのユーザ」にインストールした場合は`/Library/Screen Savers/`です。ファイルがある場合は、Appleが検証できないという警告と「プライバシーとセキュリティ」の許可表示を確認し、許可後にシステム設定を再起動してください。「このまま開く」が表示されない場合や許可後も動かない場合は、警告の文言とバンドルのバージョンを確認して切り分けます。

CIは署名の整合性とバンドル読み込みを検証しますが、ダウンロード後のGatekeeper・一覧登録・ホストからのKeychainアクセスの代わりにはなりません。

## 更新・削除

更新時はスクリーンセーバーとシステム設定を終了して、新しい`.saver`を開き、同名のバンドルを置き換えます。システム設定を開き直して「オプション」を確認してください。ホストが旧バンドルを保持する場合はログアウトして再度ログインしてください。

認証情報を削除する場合は先に「オプション」→「認証情報を削除」を使ってください。その後、システム設定で削除するか、Finderで`~/Library/Screen Savers/`内の`SwitchBotScreenSaver.saver`を削除します。バンドルを削除するだけではKeychainの認証情報は消えません。
